# HotCopy 改写模型选择

管理员在服务端配置 `LLM_MODEL` 作为自动模式的优先模型；用 `LLM_MODEL_CHOICES`（英文逗号分隔模型 ID）增加用户可选项，例如 `LLM_MODEL_CHOICES=model-a,model-b`。未显式配置的默认模型不会列为可选项。仅填当前 `LLM_BASE_URL` 与 `LLM_API_KEY` 对应服务商账号**实际支持**的模型 ID，部署前逐个做真实请求验证。当前本机的 Groq `/models` 请求返回 401，凭证需要核实，暂不把任何具体模型加入可选项。

首页「改写模型」默认自动推荐，继续使用现有模型故障切换。用户明确选择某个模型时，后端只调用这一款；模型不可用则返回失败，不会静默替换。只对 AI 改写生效，原声全文不调用大模型。前端不会拿到服务商 API 密钥，也不接受用户输入任意 API 地址或模型 ID。

模型选择目前没有额外收费规则，也没有用户自带 API Key。上线多个不同成本的模型前，先实现任务和 token 成本账本，再明确每个选项的计费与失败退还规则。
